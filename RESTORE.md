# Restaurar o projeto GetSupply

Este repositório inclui o bundle Git completo do projeto em [getsupply-project.bundle](./getsupply-project.bundle).

Para restaurar todos os arquivos e o histórico localmente:

```bash
git clone getsupply-project.bundle getsupply
cd getsupply
git checkout main
```

O bundle contém a aplicação GetSupply, o design system, o servidor de API e as bibliotecas compartilhadas.
